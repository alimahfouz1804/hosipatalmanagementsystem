# Hospital Management System

A hospital management application developed in C++ and presented as a university project for the **Data Structures course**.

## Features
- Add, update, and delete patients
- Manage doctors and nurses
- Manage hospital rooms
- Assign patients to rooms
- Manage appointments
- Search and display hospital records
- Save and load data from files
- Windows graphical user interface (GUI)

## Technologies Used
- C++
- Data Structures
- Arrays and Pointers
- Functions
- File Handling
- Windows GUI

## Academic Information
- **Course:** Data Structures
- **Project Type:** University Course Project
- **Language:** C++
- **Platform:** Windows

## Development Notes
The core hospital management system was developed for the Data Structures course. AI tools were used to assist with the graphical user interface (GUI) and data-saving functionality.

Description

This project was presented as part of the Data Structures course to demonstrate the practical application of data structures and C++ programming concepts in managing hospital operations.
